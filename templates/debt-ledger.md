# Debt ledger

One row per pile. Never delete a row; move it to `retired` with the date and the proof.

| Pile | Where it hides (infra / ops / knowledge) | Principal (the shortcut) | Interest per week (hours, pages, blocked changes, carrying cost) | Source for each figure | Confidence (measured / estimate) | Owner (role, not name) | Status (open / in repair / retired) | Proof of retirement |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

Weekly check: did any open row's interest grow? Did anything get added by the daily loop? Which row is next week's pile?
